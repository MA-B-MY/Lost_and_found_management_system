# Lost and Found Management System

A web-based Lost and Found Management System developed as a Final Year Project for Universiti Kuala Lumpur (UniKL). This application streamlines the process of reporting, tracking, and claiming lost items on campus with secure authentication, advanced search capabilities, and automated email notifications.

## Features

- **Item Reporting:** Report lost or found items with detailed descriptions, categories, and images.
- **Advanced Search & Filter:** Quickly search through items by keywords, categories, dates, and status.
- **Claim Management:** Secure workflow for users to submit claims and for administrators to verify and approve them.
- **Soft-Delete Functionality:** Safely handle records without permanently erasing database entries.
- **Automated Email Notifications:** Integrated SMTP configuration to send status updates and notifications regarding item claims.
- **Admin Dashboard:** Centralized control panel for managing users, reports, and system configurations.

## Tech Stack

- **Backend:** PHP (Native)
- **Database:** MySQL / MariaDB (managed via PDO)
- **Frontend:** HTML5, CSS3, JavaScript
- **Environment:** XAMPP (Local Development)
